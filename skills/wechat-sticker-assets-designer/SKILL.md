# 微信表情配套素材

保持参考图中的角色固定特征和画风，不为了PNG格式改成扁平矢量。用户指定文案优先；示例赞赏语不是强制官方文案。不添加无关emoji、账号、二维码或品牌。

| 类型 | 本地制作尺寸 | 内容与背景 |
| --- | --- | --- |
| banner | 750×400 | 无文字故事场景，有色不透明背景 |
| reward_guide | 750×560 | 可选；期待支持，用户文案或“您的赞赏是我们最大的动力！” |
| reward_thanks | 750×750 | 可选；感谢互动，用户文案或“感谢您的慷慨赞赏！” |

场景配图背景延伸至所有边缘，避免白或接近白的边框。赞赏两张按需要成对生成，不默认代表用户同意赞赏协议。横幅目标比例15:8；引导图目标比例75:56，不能把4:3当成完全相同；致谢图1:1。

逐张独立生图，不能把三张拼成一张替代素材。生成前预留安全区，文字和脸不要贴近裁剪边缘。发生工具失败时说明缺失项，不无界重试或伪装完成。

## 保留原图的加工

```bash
python3 <skill-dir>/scripts/crop_and_resize.py input.png   --width 750 --height 400 --anchor center   --output output/banner.png --max-bytes 512000
```

默认输出旁边的`原文件名-宽x高.png`；明确输出路径更便于归档。拒绝覆盖输入和已有输出。比例不符按anchor裁剪，绝不拉伸；字幕优先top，仍需检查有无切断文字。

PNG先无损保存；超过显式体积目标时，对不透明场景图尝试带抖动的调色板压缩，不改变像素尺寸。透明图不自动牺牲alpha以压缩；无法满足目标时明确失败。保留原始源图；压缩后视觉检查色带、文字、毛发，不能仅凭文件大小判断质量。

完整表情包由[制作入口](../wechat-sticker-maker/SKILL.md)复用本脚本，保存到包内assets/，原图放source/。核对所有最终尺寸后交付，平台限制仍以提交页为准。
