# 微信红包封面设计

默认制作一张静态封面。按用户要求交付构思、预览或完整素材，收到反馈时只改指定部分，优先复用已选画稿。

1. **定风格。** 有指定风格、参考画稿或图库编号时直接沿用。风格未定时才参考[风格目录](references/styles.md)，按题材选贴合的方向。只有用户要求看风格样张或对比时才展示相关图库。
2. **画封面。** 选一个清楚的祝福意象，保留用户角色的辨识点，生成接近 3:4 的满版画稿。核对小尺寸下的主体和文案，让重要内容避开头像、昵称、祝福语和按钮可能遮挡的位置。画面文字用用户原文。
3. **复核并交付。** 按[导出、审片与打包](references/export.md)检查全图、遮挡和缩小效果。裁切反馈用原画改焦点重导，文案反馈优先复用原画或文字层。用户要整包时，从所选预览原样打包。成品注明尺寸与体积，实际效果以微信平台手机预览为准。

用户要求挂件时，按[静态挂件](references/charms.md)制作所选图层。沿用封面的材质和配色，用独立透明 PNG 表现装饰图案，再校验模板避让区。
