# 动态表情的画风与主题

画风决定角色的视觉语言，主题决定聊天场景、文案和动作。缺哪项就查哪项。已有角色优先用原画风，用户给了具体聊天场景或文案就依照它设计动作。用户明确要比较时，用同一角色、同一个代表动作对照，便于看清画风差异。条目可自由组合，交付数量按本次需求。

## 可选画风

| 方向 | 画面与动作要点 |
| --- | --- |
| Q 版色块 | 保留主要辨识点，用大色块和夸张姿势让情绪缩小后也能读懂。 |
| 写实影像 | 固定机位、光向和造型，用视线与面部微动作表达情绪。 |
| 赛璐珞手绘 | 用明确轮廓和分区阴影，转头时保持五官结构和暗面方向。 |
| 立体短绒 | 保留绒毛方向、软轮廓和高光位置，动作帧的毛发密度保持一致。 |
| 定格黏土 | 用夹、捏、压等姿势表现软质体块，以清楚的关键姿势和适度停顿体现定格节奏。 |
| 织物拼缝 | 让针脚与纹理跟随肢体，避免抬手时布纹脱离角色。 |
| 分层剪纸 | 使用明确的部件层次和转动支点，动作里保留纸边、关节与遮挡关系。 |
| 双色孔版印刷 | 利用两色叠印突出动作轮廓，颗粒随图层移动，避免逐帧重新撒点。 |
| 像素街机 | 固定像素网格与色板。先用最近邻处理到交付画布，再导出同尺寸帧。 |
| 水墨飞白 | 用实墨固定角色轮廓，把飞白或晕染留给辅助动势，检查透明 GIF 的浅墨边缘。 |
| 极简粗线 | 用稳定线宽和眉眼形变表达动作，保留手势与脸部之间的空隙。 |
| 螺钿镶嵌 | 用少量虹彩块面表现材质，局部转动才改变高光，保持轮廓可读。 |

## 可选主题

表中的文案是动作设计的例子。使用时以用户给定的文案和动作优先，可交付有字或无字版本。

| 主题 | 聊天场景 | 动作例子 |
| --- | --- | --- |
| 协作交接 | 接下来由谁处理 | 「我接手」接住文件夹，抱稳后点头。 |
| 远程会议 | 开麦、听见和插话 | 「刚才静音了」看向耳麦、按一下开关，再抬手示意。 |
| 创作卡关 | 找思路、改稿、重试 | 「再试一次」翻回空白页，停一拍后重新落笔。 |
| 情绪秒读 | 惊讶、疑惑和犹豫 | 「等等」短促后仰，抬爪停住，眼神转向对方。 |
| 温柔打气 | 安慰、陪伴和鼓励 | 「慢慢来」缓缓推过一杯温水，抬眼点头。 |
| 工位续航 | 充电、歇口气和收工 | 「先补点电」从伏桌坐起，双手抱住热杯。 |
| 出门会合 | 报到、等人和找位置 | 「到门口了」小跑收步，踮脚挥手。 |
| 同住日常 | 留饭、照顾和搭把手 | 「给你留了」把小点心盘推到画面边，扶稳后松手。 |
| 玩伴开黑 | 集合、救场和庆祝 | 「我来接」侧身跨一步，双手兜住掉下来的心形道具。 |
| 节日问候 | 聚会、生日和应节祝福 | 「讨个好彩头」举起福袋摇两下，然后收回胸前。 |

同一主题可换画风。比如「远程会议」配像素街机时，用整数像素表现抬手与按耳麦；配定格黏土时，可以突出按键前的停顿和手指压下的形变。
