# 表情包生产流程

本技能编排创意、预览和完整交付，具体图片加工复用现有脚本，不维护另一套实现。

1. 记录已确认角色、画风和16个动作文案到pack.json。
2. 生成真实透明网格，按需要由脚本排字，交付16宫格预览。
3. 用户只要预览时停止；授权整包后复用已选图片，补齐无字封面、图标、横幅及可选赞赏配图。
4. 调用build_pack.py一次导出主图、缩略图、配图、元数据、预览、检查清单和ZIP。原图保留，重跑使用新版本目录。
5. 视觉检查角色、文案和裁剪后交付绝对文件链接；本流程不操作微信草稿或提交审核。

流程约束见[SKILL.md](SKILL.md)，唯一制作说明格式见[pack.json](../wechat-sticker-maker/references/pack-spec.md)。不默认要求逐阶段确认：已授权整包时继续完成，明确只看预览时尊重范围。
