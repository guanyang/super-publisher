## 表情与动图

| 技能 | 什么时候用 | 交付 |
| --- | --- | --- |
| [sticker-factory](../skills/sticker-factory/README.md) | 从角色参考或点子开始，想制作一整套静态微信表情 | 16 宫格预览，或含主图、缩略图和配图的素材 ZIP |
| [grid-sticker-generator](../skills/grid-sticker-generator/README.md) | 已定角色和画风，只需要一张网格看效果 | 可带文案的 4×4 透明 PNG 网格 |
| [wechat-sticker-maker](../skills/wechat-sticker-maker/README.md) | 已有透明网格或 `pack.json`，需要切图、排字或打包 | 居中的 PNG，或含缩略图、配图和检查预览的微信表情 ZIP |
| [wechat-sticker-assets-designer](../skills/wechat-sticker-assets-designer/README.md) | 表情角色已定，只需要做横幅或赞赏配图 | 沿用角色画风的横幅、赞赏引导图和致谢图 |
| [animated-sticker-maker](../skills/animated-sticker-maker/SKILL.md) | 有角色参考或动作点子，需要设计循环动作 | 单张 GIF 小样或整套循环 GIF，按需附审片页和 ZIP |
| [gif-maker](../skills/gif-maker/README.md) | 已有连续帧或精灵表，需要合成、调速或压缩 | 循环 GIF、解码预览和制作记录 |

动态表情需要选画风或聊天场景时，可查[画风与主题参考](../skills/animated-sticker-maker/references/creative-directions.md)。静态表情的打包字段见 [pack.json 说明](../skills/wechat-sticker-maker/references/pack-spec.md)。
